## About
This repo contains a focused HTML page presenting a concise, non‑doctrinal overview of Samaritan Judaism in Jesus’s time. It outlines the historical context, the Torah‑based practices of the Samaritan community, and the narrative pattern match that emerges when reading the gospels through this lens.
